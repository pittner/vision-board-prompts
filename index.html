Vision Board Prompt Pack

48 free, copy-paste AI image prompts for building a vision board — career, money, health, love, travel, home, fresh start and monthly reset. Tested on Midjourney, DALL·E, Gemini / Nano Banana and Stable Diffusion.

MIT licensed · No signup · Source on GitHub

How to use these prompts

  • Replace the brackets. Every prompt has a [placeholder]. A vision board only works when the image is specific — "senior data engineer at a Berlin fintech" beats "good job".
  • Generate 2–4 variants per prompt and keep the one that gives you a physical reaction. That reaction is the whole point of a vision board.
  • Aim for 6–9 images on one board. More than that and no single image gets attention.
  • Write one concrete next action next to each image ("book the certification exam by Friday"). A board without a next action is a screensaver.
  • Style suffix — append this to any prompt for a consistent board look:
    — cohesive editorial style, warm natural light, shallow depth of field, no text, no watermark, 4:5

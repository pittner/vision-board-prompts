## How to use these prompts

1. **Replace the brackets.** Every prompt has a `[placeholder]`. A vision board only works when the image is specific — *"senior data engineer at a Berlin fintech"* beats *"good job"*.
2. **Generate 2–4 variants** per prompt, keep the one that gives you a physical reaction. That reaction is the whole point.
3. **Aim for 6–9 images** on one board. More than that and no single image gets attention.
4. **Write one concrete next action** next to each image ("book the certification exam by Friday"). A board without a next action is a screensaver.
5. **Style suffix** — append to any prompt for a consistent board look:

```
— cohesive editorial style, warm natural light, shallow depth of field, no text, no watermark, 4:5
```

6. **Assemble the images into an actual board.** Six loose PNGs in a downloads folder are not a vision board. Arrange them into one board and a matching phone lock-screen wallpaper with the [free vision board maker](https://visionboard.bemooore.com/free-vision-board-maker/?utm_source=github&utm_medium=referral&utm_campaign=prompt_pack_readme&utm_content=readme_step6) (browser-based, no signup, your photos never leave your device), or lay them out in any tool you already use.

## Contributing

New categories are welcome — open a pull request adding a section with 6 prompts in the same format. Two rules:

- **No brand names or real people** in prompts (image models handle them badly and it creates rights problems).
- **Every prompt must be specific enough to picture.** If it could describe anyone's life, it's too vague for a vision board.
